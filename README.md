# The Big Glitch (working title)

A golden-era point-and-click adventure — Monkey Island 2 / Fate of Atlantis
mood, 2026 hi-bit pixel art, modern haptics — running in browser, mobile, and
desktop from one codebase. Adapted from the story "The Big Glitch": a playable
book about the year the AI economy died of a quadrillion small errors.
